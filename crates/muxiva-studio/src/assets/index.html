TURN-BY-TURN DATA FLOW
Semantic trace
No semantic messages

              
Text, Event and graph-local Signal envelopes are grouped into turns and correlated by Frame ID, Trace ID and Sequence. Both Node input and output boundaries are shown. Payloads stay in bounded process memory and are cleared when Studio restarts.

              
Run the Graph to trace semantic messages.

            

            

              
OPT-IN DIAGNOSTICS
Node media dumps
Off · no media is stored

              
When enabled, Studio captures every Audio/Video Frame received and emitted at each Node Port. Capture is asynchronous and bounded; it never blocks the Graph. Files stay local under .muxiva/observability/media.

              
Enable the switch before or during a run to collect media diagnostics.
