## Documentation contract

Public API, Graph/Manifest Schema, Runtime semantics, Studio, CLI, provider, or
architecture changes must update `docs/` in the same pull request. The
documentation workflow builds pull requests with `mkdocs build --strict` and
publishes merged changes to this site.
